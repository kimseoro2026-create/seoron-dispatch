## 1. 요약

- **같은 인력·같은 요청으로, 신청순 배정보다 하루 4.5명(+16.2%) 더 제때 돌봄을 받았다**(최적화, ρ 0.9). 이동은 33.6% 줄었다.
- 근거리 규칙만으로도 대부분의 효과가 나온다(+4.3명). 최적화는 근거리보다 하루 0.2명 더 돌보고 이동을 38분(18%) 줄였다.
  270개 날짜·시드 조합 중 근거리보다 많이 배정한 날 49, 적게 배정한 날 0이다. 시드 10개 실험(900관측)에서도 같은 방향이다(+0.22명, 진 날 0).
- **가장 큰 병목은 인력 수가 아니라 '모든 인력의 휴게가 12시로 같은 것'이었다.** 휴게 시작만 11·12·13·14시로 나누면
  추가 인건비 없이 고유 인원이 하루 32.5→36.8명(+4.3명)으로 늘었다. 휴게를 12시에 묶어 둔 채 동행 인력을 2명 늘리면 +0.3명이다.
- 모든 배정 결과(기준선 포함)는 독립 검증기를 통과했다. 하드 제약 위반은 전 실험 합계 0건이다.
- **병원동행을 대중교통으로 계산하면 결과가 크게 달라진다**(3.1절, ρ 0.9). 같은 요청이라도 최적화의 고유 인원이 하루 2.8명 줄고,
  병원동행은 요청 22.2건 중 2.1건만 배정된다. 최적화가 근거리보다 더 돌보는 폭은 +0.22명에서 +0.05명으로 줄었다.
  신청순 대비 이점(+2.7명)은 남았지만, 이 조건의 병목은 배정 방식이 아니라 긴 동행 점유시간과 휴게 시각이다.
  대중교통에서도 휴게 분산은 추가 인건비 없이 하루 29.6→35.3명(+5.7명)으로 늘렸고, 휴게를 묶어 둔 채 동행 인력만 늘리면 변화가 없었다(5.2절).
- **인력이 다음 집으로 대중교통을 타고 가면**(3.2절, ρ 0.6·0.9·1.1, 비율 0·50·100% 비교): 인력 절반이 대중교통이면 고유 인원 변화는 하루 0.2명 이내,
  모두 대중교통이면 최적화 기준 0.8~1.2명 줄었다. 대신 인력 이동시간이 크게 늘었다(ρ 0.9 하루 148분 → 330분(절반) → 868분(모두)).
  모두 대중교통·ρ 1.1에서 최적화가 근거리보다 하루 +0.49명 더 돌봤다(진 날 0).
- **실제 인력은 대중교통이라(2026-11-18 확인) 휴게·시간창 실험도 그 조건으로 다시 돌렸다**(4·5.1·5.2절 끝). 병원동행 픽업창을 대중교통 시간에 맞추면(5.2절 끝),
  추가 인건비 없이 가장 좋은 조합은 **휴게 분산 + 동행 인력 절반만 1시간 일찍 출근**으로 하루 29.1→34.2명(+5.1명)이다. 동행 인력 2명 추가 채용(+5.2명, 하루 208,000원)과 비슷하다.
  이 조건에서 최적화는 근거리보다 하루 +1.7명 더 돌봤다(90일 중 이긴 날 62, 진 날 2). 병원동행은 여전히 22.3건 중 4.7건만 배정된다.
- 제출서의 '1.45배 지원'·'31% 절감'은 **확인되지 않았다.** 가장 좋은 조건에서 적기 배정 1.22배(ρ 1.1), 이동 33.6% 감소(ρ 0.9)였다.

### 3.1 병원동행을 대중교통으로 계산하면 (출처: `numbers_m2.md` 4절, `lab-m2-{car,transit,fixed}_r0.9-20261117-*.csv`, 각 900행, 위반 0)

병원동행의 집→병원·병원→집만 바꾸고, 인력이 다음 집으로 가는 이동은 그대로 자동차로 두었다.
대중교통은 ODsay 대중교통 길찾기 1,386구간이고, 700m 이내 68구간은 도보(시속 3km 가정)로 계산했다. 동행 왕복 이동은 평균 약 15분에서 약 50분으로 늘었다.

ρ 0.9, 30일 × 시드 10개, 하루 평균.

|---|---|---|---|---|---|
| 자동차 가정 | 55.1 | 0.88 | 28.0 / 32.4 / 32.6 | 5.4 / 22.2 | +0.22 (54 / 0) |
| 대중교통, 같은 요청(수요 고정) | 55.1 | 0.98 | 27.0 / 29.7 / 29.8 | 2.1 / 22.2 | +0.05 (16 / 0) |
| 대중교통, 부하율도 대중교통 기준 | 50.4 | 0.89 | 25.5 / 27.4 / 27.4 | 1.9 / 20.1 | +0.04 (12 / 0) |

- 다른 부하율에서도 방향은 같다(같은 요청 기준, 최적화 고유 인원): ρ 0.6 23.1 → 20.9명, ρ 1.1 34.7 → 31.9명.
  최적화 − 근거리는 ρ 0.6 +0.09 → +0.02, ρ 1.1 +0.29 → +0.16명이고, 세 부하율·세 시나리오 모두 진 날은 0이다(2,700관측, 위반 0).
  신청순 대비 최적화 이점은 ρ 1.1에서 +6.0 → +3.9명으로 남지만, ρ 0.6에서는 +1.0 → +0.3명으로 작아진다.
- 같은 요청에서 이동 가정만 바꾸면 (ρ 0.9) 고유 인원이 신청순 −1.0, 근거리 −2.7, 최적화 −2.8명 줄었다. 줄어든 몫은 대부분 병원동행이다(최적화 동행 배정 −3.3건).
- 동행 1건의 점유시간(이동+병원 체류, 30일 요청 728건)은 자동차 가정 중앙값 3.2시간(10~90% 구간 2.4~4.0)에서
  대중교통 3.9시간(3.0~4.9)으로 늘었다. 이렇게 길어지면 12시 휴게를 피해 넣을 수 있는 자리가 거의 없다. 그래서 방식끼리 차이가 작다.
  배정 방식보다 **휴게 운영과 동행 점유시간**이 먼저 풀어야 할 병목이라는 5.2절의 결론이 더 강해진다.
  5.1·5.2절에 같은 요청으로 대중교통 가정 결과를 함께 실었다. 휴게 분산의 효과(+5.7명)는 그대로 남는다.
- 대중교통 시간은 출발 시각을 반영하지 않는다(ODsay에 출발 시각 요청변수가 없음). 출근 시간대와 낮 시간대 배차 차이가 빠져 있다.

### 3.2 인력이 대중교통으로 다니면 (출처: `numbers_m2.md` 5절, `lab-m2-wk{0,50,100}_r{0.6,0.9,1.1}-20261118-*.csv`, 9개 각 900행, 위반 0)

병원동행 집↔병원은 세 경우 모두 대중교통이고, 요청은 3.1절 '수요 고정'과 같다. 바꾼 것은 **인력이 다음 집으로 가는 수단**뿐이다.
실제 자차/대중교통 비율은 확인되지 않아 0% / 50% / 100% 세 시나리오로 나눴다(자격 묶음마다 같은 비율).

대중교통 인력의 이동은 ODsay 표본 400쌍으로 맞춘 보정 모형 값(estimate)이다:
`min(1.48 × 자동차분 + 20.3, 직선거리 × 1.30 ÷ 시속 4km) + 여유 9.4분`. 여유는 학습 오차의 80% 분위수다.
검사용 120쌍에서 평균 오차 10.7분, 실제보다 10분 넘게 짧게 잡은 구간은 3.3%였다.

|---|---|---|---|---|---|
| 0.6 | 0% | 20.6 / 20.8 / 20.9 | 1.4 / 15.1 | 95 | +0.02 (7 / 0) |
| 0.6 | 50% | 20.4 / 20.8 / 20.8 | 1.4 / 15.1 | 162 | +0.01 (2 / 0) |
| 0.6 | 100% | 20.0 / 20.1 / 20.1 | 0.8 / 15.1 | 587 | +0.03 (10 / 0) |
| 0.9 | 0% | 27.0 / 29.7 / 29.8 | 2.1 / 22.2 | 148 | +0.05 (16 / 0) |
| 0.9 | 50% | 27.0 / 29.6 / 29.7 | 2.0 / 22.2 | 330 | +0.09 (13 / 0) |
| 0.9 | 100% | 26.2 / 28.5 / 28.8 | 1.3 / 22.2 | 868 | +0.27 (61 / 0) |
| 1.1 | 0% | 28.0 / 31.7 / 31.9 | 2.2 / 24.1 | 168 | +0.16 (37 / 0) |
| 1.1 | 50% | 28.1 / 31.5 / 31.8 | 2.1 / 24.1 | 384 | +0.22 (30 / 0) |
| 1.1 | 100% | 27.0 / 30.2 / 30.7 | 1.3 / 24.1 | 937 | +0.49 (90 / 0) |

(이긴 날 / 진 날은 같은 날·같은 시드 300번 비교 중의 날 수.)

- 돌본 사람 수는 생각보다 적게 줄었다(모두 대중교통일 때 최적화 기준 ρ 0.6 −0.8, ρ 0.9 −1.0, ρ 1.1 −1.2명/일). 이미 휴게 시각과 동행 점유시간이 병목이라, 인력 이동이 길어져도 남는 빈 시간이 먼저 줄어든다.
  대신 인력의 이동시간이 크게 늘었다. 이동시간은 근무시간이므로 인건비·피로 문제로 이어진다(비용은 계산하지 않았다).
- 인력이 모두 대중교통일 때 최적화와 근거리의 차이가 다시 커졌다(ρ 0.9 +0.05 → +0.27명, ρ 1.1 +0.16 → +0.49명, 진 날은 모두 0). 이동이 길고 일이 몰릴수록 묶기·순서 조정의 효과가 커진다.
  일이 적은 ρ 0.6에서는 세 방식이 거의 같다(차이 0.03명 이하) — 남는 인력이 있으면 배정 방식보다 수요가 결과를 정한다.
- 엔진은 모형 값으로 계산하므로, 담당자에게 보일 후보안은 연결 구간만 실제로 다시 조회해 검증한다(`python -m adapters.fetch worker-plan`).

  인력 여유 부족은 0.4%다. 인력이 대중교통이면 **근무 시작 후 동행 어르신 집에 제때 도착하지 못하는 동행**이 늘어난다.
- 병원동행 미충족률 94.5%, 희망 시작 11시 요청은 100% 미배정이다. 이 조건에서 병원동행을 늘리려면 픽업창·근무 시작 시각·동행 전담 인력의 출발지를 함께 봐야 한다.

**픽업창을 대중교통 시간에 맞추고, 동행 인력 출근 시각을 바꾸면** (출처: `shortage-20261119-011836.csv`, 1620행, 위반 0, 위와 같은 요청 · `docs/reports/shortage_report.md`)

위 결과를 따져 보니, 가상 자료의 병원동행 픽업창은 **자동차 추정 이동**으로 만들어져 있었다(예약 − 이동 − 10~30분).
대중교통으로 계산하면 창 안에서 가장 늦게 출발해도 예약에 못 닿는 요청이 하루 6.9건이었다 — 인력을 아무리 늘려도 맡을 수 없는 요청이다.
실제 담당자는 가는 수단에 맞춰 픽업 시각을 정하므로, 같은 규칙을 대중교통 시간으로 다시 적용했다
(`config/region.yaml escort_travel.align_pickup`, 예약 시각은 그대로, 근무 시작 전으로 당겨진 창도 자르지 않음).
그 결과 픽업이 8시대로 당겨진 동행이 하루 5.4건 생겼다. 9시 출근이면 맡을 수 없어, 동행 인력(8명)의 근무를 같은 길이로 앞당기는 시나리오를 더했다.

- 근무 시각 변경(8시 출근)·휴게 분산이 근무 규정·노사 합의로 가능한지는 확인하지 않았다.
- 이 실험의 엔진 미배정 사유는 '계산 중 미해결'만 나온다. 근무 시작 전으로 당겨진 픽업창을 '시간창 충돌(확인됨)'으로 표시하도록 실행 뒤에 고쳤다
  (배정에는 영향 없음, 다음 실행부터 반영). 원인은 위 표의 진단(빈 일정 재시험)으로 본다: 현재 조건 병원동행 미배정 중 휴게 충돌 12.5건 · 시간창·근무시간 불일치 8.0건/일.

## 7. 한계

1. **데이터가 가상이다.** 요청 시간창(동행 픽업 20분), 휴게 규칙, 서비스 시간은 합성 가정이다. 실제 기관 데이터로 다시 확인해야 한다.
2. 고령인구는 실제 행정동별 인구(행안부)지만, 연령이 10세 구간이라 65세 이상은 '70세 이상 + 60대 절반' 대략값이다. 어르신 개인은 합성이다.
3. 최적화는 근거리 해를 10초 동안 개선하는 방식이며 최적 증명은 없다. 휴게를 분산하면 일부 날짜에서 근거리 해를 읽지 못해
   빈 일정에서 출발한다(결과는 모두 검증 통과).
4. 최적화 엔진은 미배정의 원인을 증명하지 못해 '계산 중 미해결'로 남긴다. 5.2의 진단은 진단용 재시험이지 엔진의 확정 사유가 아니다.
5. 비용은 시급 가정 하나로만 계산했다. 월급제·교통비·교육비는 넣지 않았다.
6. 1.45배·31% 절감은 확인되지 않았다.
6-1. 3~5절 본문 표는 병원동행을 자동차로 계산했다. 대중교통 결과(3.1절, 4·5.1·5.2절 끝)는 출발 시각을 반영하지 않으며, 700m 이내 도보 속도(시속 3km)는 가정값이다.
   인력의 집 사이 이동은 3.2절과 4·5.1·5.2절 맨 끝 블록이 대중교통이고(2026-11-18 사용자 확인: 실제 인력은 대중교통), 3절 본표와 그 밖의 블록은 자동차다.
   대중교통 인력 이동은 보정 모형(estimate)이며 인력 보행 속도(시속 4km)는 확인되지 않은 가정이다. 담당자에게 보일 안은 연결 구간을 실제로 다시 조회해 확인한다.
   병원동행 픽업창은 4·5.1·5.2절 마지막 블록만 대중교통 시간에 맞췄다. 3.1·3.2절과 그 밖의 대중교통 결과는 자동차 기준 픽업창이다.
   4·5.1절에서 비교해 보니 차이는 작았다(20분 창 적기 배정 +0.5건, 취소·지연 대응 결론 같음).
