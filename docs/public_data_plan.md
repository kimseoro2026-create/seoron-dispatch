- 조사일: 2026-11-16 (각 사이트 화면을 직접 확인. '확인 필요'는 아직 못 본 것)
- 목적: 판매 단계에서 민간 지도 API 요금·약관에 기대지 않도록, 이동시간은 OSRM(자체) + 공공 소통정보 보정으로,
  주소→좌표는 공공 API로 해결한다.

### 쓰지 않기로 한 것

- **브이월드 지오코더**: 하루 40,000건 무료지만, 레퍼런스에 "별도의 저장장치나 데이터베이스에 저장할 수 없습니다"라고 적혀 있다.
  어르신 집 좌표를 저장해 배정에 써야 하므로 맞지 않는다.
- **화성시 자체 소통정보**: 공공데이터포털에서 찾지 못함(0건). 국가·경기도 자료로 대신한다.

## 이렇게 쓴다 (구현 계획)

1. 표준노드링크에서 동탄 범위 링크만 잘라 저장한다.
2. 소통정보 파일(지자체·국도)에서 그 링크들의 시간대별 통행시간 중앙값을 만든다(평일, 여러 날).
3. 같은 링크를 OSRM으로 계산해 `실측 통행시간 ÷ OSRM 시간` 비율을 구한다 → 시간대별 `OSRM_TIME_FACTOR`.
4. 이동시간 행렬 source 는 `osrm` 그대로 두고, 보정 계수와 그 근거(링크 수·기간·덮인 도로 비율)를 summary 에 남긴다.
   보정 근거가 부족한 시간대는 보정하지 않고 '보정 안 됨'으로 표시한다(지어내지 않음).
5. 골목·단지 안 도로는 소통정보가 없을 가능성이 크다 → '간선도로 기준 보정, 단지 안 도로는 OSRM 기본값'으로 보고서에 적는다.

## 사용자가 할 일

1. **its.go.kr 회원가입 → 오픈데이터 인증키 신청**(교통소통정보). 키는 `.env` 에 직접 넣는다(예: `ITS_API_KEY=`).
2. **data.go.kr 에서 '경기도_구간 소통 정보' 활용신청**(자동승인). 공공데이터포털 키를 이미 쓰고 있다면 같은 키.
3. **business.juso.go.kr 에서 좌표제공 검색 API 신청** → 승인키를 `.env` 에 (예: `JUSO_COORD_KEY=`).
4. 캡처 요청: 경기도 구간 소통 정보 상세(요청변수·응답 항목), 도로명주소 좌표 검색 API 상세(요청변수·응답·좌표계), 표준노드링크 다운로드 화면.
5. 내려받기: 표준노드링크 최신 파일 1개, 지자체 소통정보 하루 파일 몇 개(평일). 큰 파일이라 받기 전에 파일명·크기를 확인하고 진행한다.

## 판매 전 확인

- its.go.kr 오픈데이터 이용 조건(파일 데이터의 상업 이용·재배포), 도로명주소 API 이용약관.
- 공공데이터포털 두 API는 '이용허락범위 제한 없음'으로 확인했지만, 운영 단계 트래픽 한도는 기관 정책에 따라 다르다고 적혀 있다.
